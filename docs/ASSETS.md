## Mixamo, considered and declined

The brief asked to try Mixamo for animation. Tried, and set aside, for two reasons that both hold on
their own:

- **It is login-gated.** Every character and clip sits behind an Adobe ID and a browser session; there
  is no anonymous endpoint a build tool could call, so nothing here could fetch one, and a pipeline
  that needs a human to click through Adobe every time is not a pipeline.
- **Its terms forbid what this repository is.** Mixamo assets are royalty-free in a project, but the
  raw character and animation files may not be redistributed on their own. This project vendors its
  assets into a public repository and ships them inside a release, which is exactly the standalone
  redistribution the licence rules out.

So the animation stays where it was: the KayKit packs (CC0, credited in the table above) retargeted
onto the player's rest by `tools/rig_player.py`, plus the two clips no shelf carries - swimming -
synthesised from published stroke kinematics in `web/src/core/swimclip.py`. The citizen and police
bodies are generated in `web/src/world/people/citizens.js` and borrow only the skeleton.
